**不是多签！**  
**不是 wallet.dat！**  

根据笔者多年折腾各类方案的经验，**BIP39 助记词 + passphrase 才是当前适合大多数人的答案**。你不需要花太多时间、不需要了解奇怪技术名词，就能构建既简单、同时安全性不亚于多重签名的托管方案（是的，不亚于！）。


> 创建钱包 = 创建助记词 + passphrase


围绕 BIP39 助记词 + passphrase 路线，开发工具、创建文字视频攻略，进一步降低技术复杂性，才是让比特币走向广大群众的正路。
